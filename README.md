# NexHaven Systems Website

Responsive one-page marketing site for NexHaven Systems LLC and Atlas OS.

## Publish with GitHub Pages

1. Create a private or public repository named `nexhaven-website`.
2. Upload `index.html`, `styles.css`, `script.js`, and `privacy.html` to the repository root.
3. Open **Settings → Pages**.
4. Choose **Deploy from a branch**, then `main` and `/ (root)`.
5. Save and wait for the published URL.

## Before public launch

- Confirm the legal company name and public contact details.
- Add a real scheduling link when available.
- Have qualified counsel review the privacy policy.
- Do not claim HIPAA compliance until the required safeguards, agreements, policies, and systems are in place.
- Do not collect protected health information through this public site or ordinary email.
